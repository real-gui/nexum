# Nexum

**Ninguém aprende sozinho.**

O Nexum é um projeto desenvolvido por alunos do programa **PROA Transforme-se**, com o objetivo de criar uma plataforma que conecte estudantes a mentores voluntários, facilitando o acesso à orientação e ao compartilhamento de conhecimento.

A proposta é permitir que estudantes encontrem pessoas dispostas a ajudá-los em diferentes áreas de aprendizado, promovendo uma comunidade baseada na colaboração.

## Funcionalidades planejadas

- Cadastro e acesso de estudantes e mentores.
- Busca de mentores por área de conhecimento.
- Visualização de perfis e disponibilidade dos mentores.
- Simulação de agendamento de mentorias.
- Painéis para estudantes e mentores.
- Avaliação das mentorias realizadas.

## Tecnologias

O projeto será desenvolvido utilizando:

- HTML
- CSS
- JavaScript

## Sobre o projeto

O Nexum está sendo desenvolvido por uma equipe de seis alunos do programa PROA Transforme-se.

O projeto busca facilitar o acesso à educação por meio de uma plataforma que conecta estudantes e mentores voluntários, incentivando a troca de conhecimentos e a aprendizagem colaborativa.
